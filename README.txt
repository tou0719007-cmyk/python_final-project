Python任务管理系统


一、项目简介

本项目是一个使用 Python 语言进行开发的命令行任务管理系统。用户可以通过控制台菜单完成任务的添加、查看、完成、删除、搜索、筛选和统计等操作，并支持任务数据保存、报表输出和图表可视化。


二、项目运行方法

1. 电脑已安装 Python

2. 将项目代码下载或克隆到本地

3. 使用终端进入项目文件夹

4. 运行以下命令：

   python main.py

5. 根据程序显示的菜单选择对应功能


三、项目文件及功能

main.py
    程序入口，负责显示菜单、接收用户选择，
    控制程序整体运行流程。

task.py
    定义 Task 类，负责任务的基本数据结构，
    包含标题、优先级、截止日期和状态。

task_manager.py
    负责任务的添加、查看、标记完成、删除、搜索、
    筛选和统计等任务管理功能。

storage.py
    负责任务数据的保存和读取，实现任务数据持久化。

report.py
    负责报表输出。

chart.py
    负责图表可视化，并与 OpenCV 加分项相关。
